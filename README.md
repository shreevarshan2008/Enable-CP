# Enable CP

Enable copy, paste, right-click and text selection on websites and online code editors that block them.

Made with ❤️ by **S.Shreevarshan** · [Instagram](https://www.instagram.com/__shreevarshan__s) · [GitHub](https://github.com/shreevarshan2008)

## Features
- Unlocks text selection, right-click, copy, cut and paste
- Stops sites from cancelling Ctrl+C, X, V and A
- Fixes blocked copy and paste in online code editors, including CodeMirror 6
- Pastes at the cursor position
- ON/OFF switch with a toolbar badge
- Optional on-screen messages that show what happened
- Collects no data and makes no network requests

## Install
1. Click the green **Code** button, then **Download ZIP**, and unzip it.
2. Open `chrome://extensions` in Chrome and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.
4. Pin the extension from the puzzle-piece icon.
5. Reload any website that was already open (Ctrl+R).

## How to use
Check that the badge says **ON**. Copy with **Ctrl+C** and paste with **Ctrl+V**. Click the icon to turn the extension or the on-screen messages on or off.

## Limits
- It cannot copy text drawn as an image or canvas.
- A website can change at any time, so a future update may be needed.

## Use responsibly
Use this extension only where it is allowed, and follow your school's and website's rules.

## Tech
JavaScript, HTML, CSS and JSON, using Chrome Extension Manifest V3. No outside libraries.
